# A/B Testing from the Ground Up

A beginner-friendly course for learning how to plan, analyse, and explain experiments. You do not need to know Python to start.

## Start here

1. Read the printable course book, main.tex, for the ideas in order.
2. Open notebooks/00_getting_started.ipynb in Google Colab. Read the text, then run each code cell from top to bottom.
3. Try the exercises before looking at solutions/ANSWER_KEY.md.
4. Use glossary.md whenever a technical word is new.
5. Finish with capstone.md and notebooks/09_capstone.ipynb.

Google Colab is an interactive workbook that runs in your browser. Open Colab, choose File → Upload notebook, and select one of the .ipynb files from this repository. The course uses small, made-up data so you can practise safely.

The core path is workbooks 00–06 and 09. The other workbooks are optional next steps.

## How this course teaches

Each lesson gives a plain-English explanation first, then the technical term and its meaning. Code is introduced gradually. You can learn the experiment ideas before writing code.

The supplied notes suggested an advanced course and 25 AI tutor prompts. This course keeps their useful topics, but begins at the basics because you said you are new to coding. Instructions inside the notes are examples, not instructions for the course.

## Files

- main.tex — printable lessons.
- notebooks/ — Colab workbooks.

- capstone.md — final project and report template.
- AI_TUTOR_PROMPTS.md — 25 prompts for asking an AI tutor for hints and explanations.
- solutions/ANSWER_KEY.md — suggested answers.
- SOURCES.md — research papers and official software guides.
